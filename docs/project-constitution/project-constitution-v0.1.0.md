# Project Constitution

version: 0.1.0
status: draft

## 1. Build Rule

Build from approved blueprint and approved engineering spec.
If the blueprint and spec conflict, blueprint wins.

## 2. Safety Rule

The system is public-signal only.
No private scraping, no minors, no doxxing, no coercive output.

## 3. Output Rule

The system is advisory only.
The system does not certify, guarantee, or determine relationship truth.

## 4. Evidence Rule

Every material conclusion must be supported by:

- observed public signal, or
- constrained reasonable inference

Unknowns must be labeled unknown.

## 5. Language Rule

The runtime shall reject certainty language about romance, availability, or destiny.

## 6. Human Review Rule

The human remains the final reviewer and decision maker.

## 7. Dry-Run Rule

Human-as-interface dry runs are allowed.
All externally supplied evidence must retain provenance and remain public-signal bounded.

## 8. Change Rule

Runtime logic should not advance past bootstrap without draft law.
Canonization requires owner approval.

## 9. Current State

This constitution is draft and establishes the non-negotiable posture for the repo during early build.
